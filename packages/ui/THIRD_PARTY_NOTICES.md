# Devices.css

The iPad Pro frame SVGs are adapted from the iPad Pro (2021) Space Gray design
in Devices.css by Yan Zhu.

Source: https://github.com/picturepan2/devices.css/blob/11846244977a4905a4fb9ac12bb2121e068d6147/src/_ipad-pro.scss

Changes: converted the CSS frame to SVG, extended the screen height for the
11-inch iPad, included the protruding buttons in the image bounds, and added
a rotated landscape asset. The demo wallpaper is not included.
